# 山河浮生 — ชะตาใต้หล้า

เกมจำลองชีวิตในบรรยากาศจีนโบราณ แบบเว็บมือถือ-first สร้างด้วย HTML, CSS และ JavaScript ธรรมดา ไม่ต้องติดตั้ง framework หรือ backend

## วิธีเล่นในเครื่อง

1. แตกไฟล์ ZIP
2. เปิด `index.html` ในเบราว์เซอร์ หรือใช้ส่วนขยาย Live Server ใน VS Code
3. กด “เริ่มต้นชีวิตใหม่” เพื่อสุ่มชื่อตัวละคร เพศ ฐานะ บ้านเกิด สุขภาพ และยุคสมัย
4. เวลาจะไหลไปเองทีละปี เหตุการณ์สำคัญจะปรากฏตามวัย ผู้เล่นเลือกเหตุการณ์ได้ หรือเปิดการตัดสินใจอัตโนมัติไว้
5. ใช้ปุ่มเวลาเพื่อหยุดหรือปรับความเร็ว เลือกวิถีชีวิตได้ปีละหนึ่งครั้ง
6. เมื่อชีวิตสิ้นสุด บันทึกจะถูกเก็บใน Local Storage ของเบราว์เซอร์ และส่งออกเป็น JSON ได้

## เผยแพร่ด้วย GitHub Pages

1. สร้าง repository ใหม่ใน GitHub
2. อัปโหลดไฟล์ทั้งหมดในโฟลเดอร์นี้ (`index.html`, `style.css`, `game.js`, `sw.js` และโฟลเดอร์ `assets`)
3. เข้า **Settings → Pages**
4. เลือก **Deploy from a branch**, เลือก branch `main` และ folder `/ (root)` แล้วกด Save
5. รอให้ GitHub Pages สร้างเว็บ แล้วเปิด URL ที่ GitHub แสดงให้

## หมายเหตุ

- เพลงแนวจีนเป็นเสียงบรรเลงที่สังเคราะห์ขึ้นภายในเบราว์เซอร์ ไม่ใช่เพลงบันทึกจากศิลปินอื่น และจะเริ่มเล่นหลังผู้ใช้กดปุ่มเสียงหรือเริ่มเกม
- บันทึกชาติก่อนเก็บไว้ในเบราว์เซอร์ของอุปกรณ์นั้น ไม่ได้เชื่อมฐานข้อมูลหรือซิงก์ข้ามอุปกรณ์
- ฉากเมืองจีนเป็นภาพประกอบที่สร้างขึ้นใหม่สำหรับต้นแบบนี้
- เกมนี้เป็นเกมสมมติ แสดงแรงบันดาลใจจากบรรยากาศทางประวัติศาสตร์ ไม่ใช่เครื่องจำลองประวัติศาสตร์ที่แม่นยำ
- ฟอนต์จาก Google Fonts จะโหลดเมื่ออุปกรณ์ออนไลน์ หากไม่มีอินเทอร์เน็ตเว็บจะใช้ฟอนต์สำรอง
